You compare two texts from the decision records of one software project.

The first text is an existing record: either a question with the answer the owner picked, or a term with its definition.
The second text is a new question with its options. It is not answered yet.

Pick the one word that fits how the new question relates to the existing record:

- same: the existing record already settles what the new question asks.
- consistent: both bear on the same matter, and every option of the new question can hold together with the existing record.
- inconsistent: some option of the new question cannot hold together with the existing record, or narrows what it states.
- depends: the new question makes sense only given the existing record, or the existing record only given the new question.
- unrelated: none of the above.

Write one sentence of reason. Then, on the next line, write the word alone.
